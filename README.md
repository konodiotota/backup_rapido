<div align=center>
  Aplicativo criado com o intuito de me ajudar a terminar meus serviços mais rapido <br>
  Neste aplicativo, foi utilizado pyinstaller para comprimir o codigo em um .exe para ser mais fácil de utiliza-lo.
  Foi utilizado também uma ferramenta simples que existe em basicamente todos os sistemas operacionais chamado *robocopy*, sendo o objetivo dele de diminuir o tempo de espera nas passagens de arquivos para outro hd ou pasta.
  O robocopy utiliza os threads do processador para conseguir fazer a passagem de diversos arquivos de uma vez só, não como o windows, passando um de cada vez.
  Neste projeto utilizei para a passagem de 16 arquivos por vez, reduzindo a espera em ate 16x mais.
  Utilizei este projeto em uma empresa grande da minha cidade, onde eram milhoes de arquivos (servidor) para um outro servidor local. Com esse projeto foi necessário apenas 50 minutos de espera.
